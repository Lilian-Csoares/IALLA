# IALLA - Plataforma de Eventos

## Sobre o projeto

O IALLA é uma plataforma digital desenvolvida como
projeto acadêmico, com o objetivo de conectar pessoas
a eventos, experiências e estabelecimentos.

## Objetivo

Facilitar a descoberta de eventos, a interação entre
usuários e a divulgação de oportunidades por produtores.

## Funcionalidades planejadas

- Cadastro de usuários
- Cadastro de produtores
- Descoberta de eventos
- Localização de eventos
- Seguidores e interações
- Publicações e stories
- Favoritos e interesses
- Ingressos digitais
- Check-in por QR Code
- Notificações e mensagens

## Tecnologias

- JavaScript
- React Native
- Node.js
- MongoDB
- Expo
- Git e GitHub

## Banco de dados

O diretório database contém o script de configuração
do banco MongoDB, incluindo coleções, validações e índices.

## Projeto acadêmico

Desenvolvido como projeto final de faculdade.
